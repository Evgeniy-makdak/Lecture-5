# Лекция 5: Геометрическая оптика — как линзы собирают луч в пятно

Курс «Физика лазеров для аддитивных (3D) технологий».

## Файлы

- `Лекция_5_Геометрическая_оптика.pptx` — слайды
- `Лекция_5_Раскадровка_для_лектора.pdf` — раскадровка с текстом для лектора
- `Лекция_5_Геометрическая оптика.docx` — текстовая версия

## Темы

- Плотность мощности **I = P/S** и связь с оптикой
- Закон Снеллиуса и работа линзы
- Числовая апертура **NA = n·sin θ**, размер пятна **d ≈ λ/NA**
- Глубина резкости **DOF ≈ λ/NA²** и три практических случая
- Параметр качества пучка **M²**
