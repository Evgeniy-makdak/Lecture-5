## Тема

Базу геометрической оптики (отражение, преломление, зеркало, тонкая линза) слушатели уже знают — в этой лекции она не повторяется.

Фокус лекции:

- плотность мощности **I = P/S** и роль оптики;
- два языка: лучи (геометрия) и волны (дифракция, интерференция в фокусе);
- числовая апертура **NA = n·sin θ**, размер пятна **d ≈ λ/NA**;
- оптический тракт СЛП: волокно → коллиматор → гальво → F-θ → защитное стекло;
- глубина резкости **DOF ≈ λ/NA²** и три практических случая;
- фокус на практике: z-offset и чистота оптики;
- параметр качества пучка **M²**.

Целевой хронометраж: **35–40 минут**.
